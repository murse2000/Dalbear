# Dalbear

Apple Silicon 전용 macOS 메뉴 막대 유틸리티입니다. 마우스 휠 반전과 부드러운 스크롤, Safari 옆 버튼, 잠자기 방지, 화면 꾸미기, 폴더 허브를 제공합니다. macOS 13 이상에서 실행합니다.

## 설치

[릴리즈](https://github.com/murse2000/Dalbear/releases/latest)에서 `Dalbear-0.1.0-arm64.dmg`를 내려받아 엽니다. Dalbear 아이콘을 Applications 폴더로 드래그한 뒤 응용 프로그램 폴더에서 실행하세요. 기존 앱은 먼저 종료하고 중복 복사 대신 교체합니다.

휠 반전과 Safari 옆 버튼을 사용하려면 설치한 Dalbear에 손쉬운 사용 권한을 허용하세요. 자동 실행은 설치한 앱의 **로그인 시 자동 실행**에서 켭니다.

현재 릴리즈는 로컬 서명 빌드이며 Developer ID 서명과 Apple 공증은 포함하지 않습니다. 인터넷에서 내려받으면 macOS가 처음 실행을 차단할 수 있습니다. 출처를 신뢰하는 경우 [Apple의 실행 허용 안내](https://support.apple.com/102445)를 참고하세요.

## 노치 숨기기와 둥근 모서리

설정 창에서 **노치 숨기기**와 **배경화면 모서리 둥글게**를 각각 켜고 끌 수 있습니다. 처음에는 꺼져 있으며 선택한 상태는 다음 실행에도 유지됩니다.

- 노치 숨기기는 각 화면 상단에 검은 띠를 표시합니다. 내장 화면에서는 노치 높이, 노치가 없는 화면에서는 메뉴 막대 높이를 사용합니다.
- 둥근 모서리는 배경화면의 네 모서리에 12포인트 곡률의 검은 영역을 표시합니다. 노치 숨기기와 함께 켜면 위쪽 모서리는 검은 띠 바로 아래에 표시됩니다.
- 배경화면 파일을 수정하지 않고, 배경화면 위와 바탕화면 아이콘·일반 창 아래에 마우스 입력을 통과시키는 창을 표시합니다. 배경화면 변경을 감시하는 타이머는 사용하지 않습니다.
- 확장 모니터의 상단 검은 바와 둥근 모서리는 각각 별도 체크박스로 선택하며 기본값은 꺼짐입니다. 화면 구성 변경, 데스크탑 공간 전환, 잠자기 복귀 시 다시 배치합니다. 앱을 종료하거나 옵션을 끄면 즉시 제거됩니다.

화면 꾸미기는 휠 반전과 독립적으로 동작하며 손쉬운 사용 권한이 필요하지 않습니다. macOS의 메뉴 막대 불투명도 설정이나 전체 화면 앱에 따라 상단 표시가 달라질 수 있습니다.

## 폴더 허브

설정에서 **폴더 허브 사용**을 켠 뒤 화면 상단 중앙의 노치에 마우스를 올리면 곰발과 파일 패널이 나타납니다. 노치가 없는 모니터에서는 상단 중앙을 사용합니다. 메뉴의 **폴더 허브 열기**, 설정의 **폴더 열기…**, **⌘⌥→** 단축키로도 열 수 있습니다. 원본 Folder Hub 등 다른 앱이 같은 단축키를 사용하면 해당 앱을 종료한 뒤 폴더 허브를 껐다 켜 주세요.

- 상단 **+**로 작업 폴더를 추가합니다. 작업 폴더 탭 위에 마우스를 올리면 전환되고, 등록한 폴더와 마지막 작업 폴더 선택은 저장됩니다. 폴더 접근은 macOS 폴더 선택 창을 통해 허용합니다.
- 파일은 아이콘 격자로 표시하며 이미지·문서 썸네일을 지원합니다. 하단 버튼으로 목록 보기와 창 고정을 전환할 수 있습니다. 고정하지 않은 창은 마우스가 떠나면 숨겨집니다.
- 더블클릭으로 폴더 탐색·파일 열기, **Space**로 미리보기, **⌘클릭**으로 Finder에서 보기, **Control 클릭**으로 AirDrop을 엽니다. 우클릭 메뉴에서도 사용할 수 있습니다.
- 파일을 다른 앱으로 드래그하거나 패널·하위 폴더로 드롭할 수 있습니다. 패널로 드롭한 파일은 복사합니다. 브라우저 등에서 제공하는 파일 약속과 PNG/TIFF 이미지 드롭도 처리합니다.
- **⌘C / ⌘V**는 복사·붙여넣기, **⌘⌥V**는 복사한 항목 이동입니다. 우클릭 메뉴에서 이동할 폴더 선택, 이름 변경, 새 폴더, 휴지통, 공유, 다른 앱으로 열기, 정렬도 사용할 수 있습니다.
- 같은 이름의 기존 파일은 덮어쓰지 않습니다. 작업 폴더 ‘등록 해제’는 목록에서만 제거하며 원본 폴더를 삭제하지 않습니다. 여러 파일 작업 중 디스크·권한 오류가 발생하면 이미 완료된 개별 파일 작업은 유지됩니다.
- 폴더 변경 감시는 패널이 보이는 동안만 수행하고, 파일 목록 읽기와 복사·이동은 별도 큐에서 수행합니다. 휠 처리·노치 숨기기 설정과 독립적으로 동작합니다.

공개 기능·배치를 참고해 자체 구현했으며 원본 앱의 코드·이미지를 포함하지 않습니다. 곰발은 AppKit 벡터 드로잉이며, 노치에서 내려온 뒤 무작위 각도·간격으로 좌우로 움직입니다. 패널을 숨기면 애니메이션과 예약된 움직임도 중단합니다.

## 빌드 및 실행

Xcode 또는 Swift 개발 도구가 설치된 Mac에서 실행합니다.

```sh
swift test --arch arm64
bash scripts/build-app.sh
open dist/MouseWheelFix.app
```

꾸며진 DMG 설치 파일은 Python 3.9 이상이 설치된 macOS에서 다음과 같이 생성합니다. 첫 실행 시 `.build/dmg-tools`에 포장 도구를 설치합니다.

```sh
bash scripts/build-dmg.sh
```

결과물은 `dist/Dalbear-0.1.0-arm64.dmg`와 `dist/Dalbear-설치안내.txt`입니다. 기존 설정 호환성을 위해 내부 실행 파일 이름과 번들 ID는 유지합니다.

생성된 `dist/MouseWheelFix.app`을 응용 프로그램 폴더로 옮긴 뒤 실행하는 것을 권장합니다. 실행 위치를 정한 뒤 손쉬운 사용 권한을 허용하세요.

1. 앱에서 **손쉬운 사용 권한 설정 열기**를 누릅니다.
2. 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 Dalbear를 허용합니다. 목록에 없다면 + 버튼으로 앱을 추가합니다.
3. **마우스 휠 반전 · 부드러운 스크롤 사용 중** 상태를 확인합니다.
4. macOS의 **자연스러운 스크롤**이 켜져 있으면 휠을 위로 돌릴 때 위로, 아래로 돌릴 때 아래로 스크롤됩니다. 이미 원하는 방향으로 움직이면 반전을 끄세요.

창을 닫아도 실행되며 메뉴 막대의 Dalbear 아이콘으로 설정을 다시 엽니다. 반전 설정은 저장됩니다. 메뉴의 종료를 선택하면 원래 스크롤 동작으로 돌아갑니다.

## 잠자기 방지

메뉴 막대의 Dalbear 아이콘 → **잠자기 방지**, 또는 설정 창의 **잠자기 방지…** 버튼에서 **30분 동안**, **1시간 동안**, **직접 해제할 때까지**, **끄기**를 선택합니다. 예약 종료 시각과 선택 상태를 메뉴에 표시합니다. 다른 시간을 선택하면 그 시점부터 새로 시작합니다.

Mac의 유휴 잠자기만 방지하므로 화면은 설정대로 꺼질 수 있습니다. 화면 잠금, 덮개 닫기, 사용자가 직접 선택한 잠자기와 배터리 부족에 의한 잠자기는 막지 않습니다. 잠자기·앱 종료 시 세션을 해제하고 다음 실행에는 꺼진 상태로 시작합니다.

macOS IOKit 전원 관리 API를 사용하며 관리자·손쉬운 사용 권한, 별도 프로세스가 필요하지 않습니다. 시간제 세션에 일회성 타이머 하나만 사용하고 시스템에도 만료를 설정합니다. Amphetamine의 시간제 잠자기 방지 기능에 해당하며 앱별 조건, 덮개 닫은 상태 유지 등은 포함하지 않습니다.

## 로그인 시 자동 실행

설정 창에서 **로그인 시 자동 실행**을 켜면 macOS 로그인 항목으로 등록됩니다. Mac을 켠 뒤 사용자 계정에 로그인하면 설정 창 없이 메뉴 막대에서 시작합니다. 로그인 전에는 실행하지 않습니다.

끄면 로그인 항목 등록을 해제합니다. macOS가 승인을 요구하면 시스템 설정 → 일반 → 로그인 항목에서 허용하세요. 설정 창을 다시 열면 macOS의 현재 등록 상태가 반영됩니다. 등록에 실패하면 오류를 표시합니다.

자동 실행을 켜기 전에 앱을 계속 사용할 위치에 두세요. [Apple SMAppService](https://developer.apple.com/documentation/servicemanagement/smappservice)의 기본 앱 등록 기능을 사용하며 별도 상주 도우미나 폴링 타이머를 추가하지 않습니다.

## Safari 뒤로·앞으로 버튼

**Safari 뒤로·앞으로 버튼**을 켜면 Safari가 활성화된 동안 일반 마우스의 옆 버튼을 Safari의 **⌘[ / ⌘]** 단축키로 변환합니다. 기본값은 켜짐이며 선택한 상태를 저장합니다. 손쉬운 사용 권한이 필요합니다.

- 표준 버튼 4는 뒤로, 버튼 5는 앞으로 이동합니다(Core Graphics 번호 3, 4). 중간 버튼과 나머지 버튼은 유지합니다.
- 누름과 놓음을 함께 처리하여 한 번 누를 때 한 번만 이동합니다. Chrome 등 다른 앱에서 시작한 버튼 입력은 변환하지 않습니다.
- 휠 반전을 꺼도 Safari 버튼 기능은 사용할 수 있습니다. 별도 타이머나 상주 프로세스를 추가하지 않습니다.
- 마우스 드라이버가 옆 버튼을 다른 번호나 키보드 입력으로 재지정한 경우 이 표준 버튼 변환의 대상이 아닙니다.

자동 테스트는 양쪽 버튼, 반복·놓음, 앱 전환, 옵션 해제, 다른 버튼 보존과 단축키 쌍을 검사합니다. 실제 마우스로 Safari에서 두 페이지를 연 뒤 뒤로·앞으로 이동 및 Chrome의 기존 동작을 별도로 확인해야 합니다. 단축키 기준: [Apple Safari 안내](https://support.apple.com/en-gb/guide/safari/cpsh003/mac).

## 동작 범위

- Core Graphics 이벤트 탭에서 비연속 스크롤의 세로 줄·픽셀·고정소수점 값을 반전합니다.
- 일반 세로 입력은 첫 이동을 즉시 전달하고 최대 120Hz로 분산합니다. 마지막 입력 후 약 120ms 내에 종료합니다. 타이머 스케줄링은 시스템 부하에 따라 지연될 수 있습니다.
- 방향 전환, 클릭, 수정 키 변경, 앱 전환, 잠자기, 반전 끄기에는 남은 보간 이동을 취소합니다. 가로 입력과 수정 키 조합은 보간하지 않습니다.
- 입력 큐를 누적하지 않고 남은 거리와 출력 이벤트 하나만 보관합니다. 스크롤이 끝나면 애니메이션 타이머를 제거합니다.
- 설정 UI는 AppKit으로 구성하며 창을 닫으면 해제합니다. 권한 요청 대기 중에만 권한 확인 타이머를 사용합니다.
- 가로 스크롤과 연속 스크롤은 유지합니다. 일반적인 트랙패드와 Magic Mouse의 터치 스크롤은 변경하지 않습니다.
- 장치 식별이 아닌 이벤트 종류로 구분하므로 일부 마우스 드라이버의 부드러운/연속 스크롤은 반전 대상에서 제외됩니다.
- 다른 휠 반전 앱과 함께 실행하면 서로 다시 반전할 수 있습니다.
- Safari 옆 버튼 지원 외의 사용자 지정 버튼 재지정과 스크롤 가속 기능은 포함하지 않습니다.

## 검증

자동 테스트는 양방향 세로 값 반전, 가로 값 보존, 연속/관성 스크롤 보존, 0값과 다른 이벤트 보존, 보간 거리 보존, 빠른 입력, 방향 전환, 취소, 작은 입력과 지연 프레임을 검사합니다. 실제 입력을 시스템에 보내지 않습니다.

`Tests/ManualScrollProbe.swift`는 실제 macOS 이벤트를 받는 별도 검증 창입니다. 앱 출력 이벤트 수, 연속 입력 여부와 이동 합계를 표시합니다. 배포 앱에는 포함되지 않습니다.

실기기에서는 권한 허용 후 긴 웹페이지/Finder에서 마우스 양방향, 트랙패드 양방향, 반전 끄기, 창 닫기 후 동작, 앱 종료 후 원래 동작을 확인해야 합니다. 권한 철회와 재허용도 확인하세요.

빌드 스크립트는 로컬 실행용 임시 서명(ad-hoc)을 적용합니다. **코드 변경 후 재빌드하면 손쉬운 사용 권한을 다시 등록해야 할 수 있습니다.** 설정의 스위치가 켜져 있어도 앱이 권한을 인식하지 못하면 해당 항목을 제거하고 현재 빌드의 앱을 다시 추가해 허용하세요. 외부 배포용 Developer ID 서명 및 Apple 공증, App Store 제출은 수행하지 않습니다.

참고: [Apple CGEvent](https://developer.apple.com/documentation/coregraphics/cgevent), [스크롤 데이터 필드](https://developer.apple.com/documentation/coregraphics/cgeventfield/scrollwheeleventdeltaaxis1).
