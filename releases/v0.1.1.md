Dalbear V0.1.1

- GitHub Releases를 이용한 앱 내 업데이트를 추가했습니다. 약 6시간마다 새 버전을 확인하며, 사용자가 승인해야 다운로드·설치합니다. 메뉴의 ‘업데이트 확인…’으로 직접 확인할 수도 있습니다.
- 백그라운드에서 새 버전을 찾으면 메뉴 막대에 ↑ 표시와 새 버전 메뉴를 표시합니다.
- macOS의 선호 언어에 따라 한국어·영어로 표시합니다. 지원하지 않는 언어에서는 영어로 표시합니다. 언어를 변경한 뒤 앱을 다시 실행하세요.
- 업데이트 파일과 배포 목록의 전자서명을 검증합니다.

V0.1.0에는 업데이트 기능이 없으므로 이번 버전은 DMG로 한 번 설치해야 합니다. 이후 버전부터 앱 안에서 업데이트할 수 있습니다.

현재 빌드는 Developer ID 서명·Apple 공증이 없는 로컬 서명 빌드입니다. 업데이트 후 손쉬운 사용 권한을 다시 등록해야 할 수 있습니다.

English

- Added in-app updates from GitHub Releases. Dalbear checks about every six hours; downloading and installing requires your approval.
- Background updates are indicated by an ↑ in the menu bar and a version menu item.
- Added Korean and English, following macOS preferred languages with English fallback. Restart Dalbear after changing the language.
- Update archives and feeds are verified with digital signatures.

Install this version once using the DMG because V0.1.0 has no updater. Later versions can be installed from the app. This release is ad-hoc signed, without Developer ID signing or Apple notarization; Accessibility permission may need to be granted again after updating.
