# Dalbear 아이콘

`Dalbear.png`는 내장 image_gen 도구로 제작한 앱 아이콘 원본입니다. 빌드 시 16~1024픽셀 아이콘 세트와 `Dalbear.icns`로 변환합니다. 메뉴 막대는 `DalbearIcon.swift`의 달·곰 단색 템플릿을 사용합니다.

표시 이름은 Dalbear입니다. 기존 설정과 로그인 항목 경로 유지를 위해 내부 번들 ID, 실행 파일 이름과 `dist/MouseWheelFix.app` 경로는 유지합니다.

## 생성 프롬프트

Use case: logo-brand. Create a finished premium macOS application icon for Dalbear (moon + bear), no text or letters. A single centered rounded-square midnight navy app tile, with generous transparent outer margin, true transparent background outside the tile. Inside: a large minimalist warm ivory bear head silhouette with round ears, nestled into and embraced by a luminous soft golden crescent moon. One cohesive bold memorable emblem, very simple geometric shapes, subtle polished depth and soft lighting but mostly clean vector-like design, excellent legibility at 32px. Bear face has only two tiny dark eyes and a small dark nose. Crescent curves around lower and right side of bear like a protective embrace. Midnight navy to indigo subtle tile gradient. No stars, no landscape, no extra objects, no typography, no mockup, no surrounding desktop. Square 1024x1024 composition, icon tile occupies about 86% of canvas, smooth corners, balanced Apple-style app icon proportions.
